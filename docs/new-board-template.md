# 新增 ESP32 板子信息填写模板

> 请按下面表格逐项填写。填完后我可以直接帮你生成 `src/boards/board_<你的板子>.h` 和 `platformio.ini` 里的 `[env:<你的板子>]`。
>
> 最有价值的参考资料：**官方原理图 / 官方 Arduino 例程 / 官方 GPIO 表格**。如果不知道某一项，写“不知道”或“无”即可。
